
# Exit Ticket Analyzer

A tool for analyzing and processing exit ticket feedback data.

## Features

- Parse exit ticket submissions
- Analyze feedback trends
- Generate reports
- Export data

## Installation

```bash
git clone https://github.com/yourusername/Exit-Ticket-Analyzer.git
cd Exit-Ticket-Analyzer
```

## Requirements

- Python 3.8+
- See `requirements.txt` for dependencies
